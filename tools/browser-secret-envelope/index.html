Local Secret Envelope

Encrypt a password or API token inside your browser using the recipient's one-time RSA-3072 public key. No secret or key is uploaded to this website.

Verify the website URL and the key fingerprint. A public website is not a trusted recipient by itself. Obtain a fresh public key directly from your authorized recipient and compare its fingerprint through an independent channel. Never share a private key or recovery phrase.

—

RSA-OAEP with SHA-256 (MGF1-SHA-256); one-time 3072-bit key. Browser-only; no network APIs or external code. Copying ciphertext does not install credentials. The receiving system must validate a transfer ID, expiry, intended provider and variable; this page cannot do that. The page cannot encrypt device-bound passkeys or large files. Clearing the field is best effort, not guaranteed memory erasure.
