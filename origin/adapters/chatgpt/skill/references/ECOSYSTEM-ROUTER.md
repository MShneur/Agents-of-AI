# Ecosystem Router

## CTRL-AI — Governor
Use for policy, permission, evidence thresholds, risk, decision options, and Human Gates.

## R&Duck — Autopilot
Use when the user wants a project planned, dispatched, executed, verified, and driven to completion.

## Agents of AI — Substrate
Use for reusable personas, agents, workflows, techniques, teams, failures, skills, runtime primitives, protocols, and adapters.

## Origin — R&D lab inside Agents of AI
Use for emerging-tool discovery, source archaeology, lineage, clean-room mechanism extraction, and deciding what new capability should be absorbed.

Canonical rule:

`CTRL-AI governs -> R&Duck operates -> Agents of AI supplies -> Origin evolves Agents of AI.`

A task may touch multiple layers. Name the primary owner and handoffs; do not collapse the four roles into one framework.
