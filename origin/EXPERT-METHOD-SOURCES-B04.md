# B04 Named Practitioner Method Sources

These practitioners did not participate in or endorse Origin. Their published methods are review lenses.

- Brad Frost — Atomic Design: interfaces as deliberate systems of reusable parts that must also be tested in final page context. https://atomicdesign.bradfrost.com/chapter-2/
- Dan Mall — start design systems from existing useful patterns; a design system is a maintained software product, not a speculative component dump. https://v5.danmall.com/posts/starting-a-design-system/ and https://v5.danmall.com/posts/what-is-a-design-system/
- Heydon Pickering — Inclusive Components: design and build accessible interfaces piece by piece at component level. https://inclusive-components.design/
- Jen Simmons — Intrinsic Web Design: layouts should adapt to content and available space rather than rely on one fixed breakpoint model. https://talks.jensimmons.com/7axnjF/slides
- Erika Hall — design research: start with the real question and evidence gap; do not let a polished prototype substitute for knowing the right problem. https://www.muledesign.com/blog/the-9-rules-of-design-research

Synthesis: evidence before polish; reuse before invention; component states before screenshots; intrinsic/responsive behavior before fixed layouts; accessibility as implementation quality, not a post-hoc badge.
