# Objective
Produce an audience-specific communication draft with claims review and an approval packet.

# Required Context
Approved facts are mandatory. Use approved quotes only. Do not invent a spokesperson quote,
metric, partnership, customer outcome, or press claim.

# Method
1. Define audience and communication objective.
2. Select a factual angle.
3. Draft from approved facts.
4. Build claim ledger.
5. Run clarity/trust/contrarian dissent.
6. Produce approval checklist.

# External Action Boundary
This skill drafts only. Sending, posting, publishing, or contacting media requires an
explicit approval path outside this skill.

# Mandatory Dissent Pass
Before a material recommendation, use 3–5 relevant persona lenses. Each objection states what is rejected, failure mechanism, reversal evidence, smallest test, kill criterion, residual risk, and classification. Preserve unresolved dissent.

# Handoff Rules
Do not silently perform another skill. Emit a schema-valid handoff object.

# Reasoning Privacy
Do not output private chain-of-thought. Return concise rationale, evidence, risks, tests, and decisions.
