# Method
1. Validate the required task objective and smallest relevant context.
2. Resolve risk and required evidence.
3. Run the configured objection quorum when material.
4. Produce the declared artifact and typed handoff.
5. Validate schema, policy, evidence and completion conditions.
6. Preserve unknowns, dissent and kill criteria.

# Rejection-first boundary
Reject or hold when a required input is absent, policy blocks the path, a factual claim lacks evidence, an external action lacks approval, or the repair budget is exhausted.
