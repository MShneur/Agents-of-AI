# B02 Named Method Sources

These practitioners did not participate in or endorse Origin.

- **Daniel Miessler** — Fabric's reusable pattern approach: isolate task purpose/instructions,
  classify intent, use bounded references, decompose complex work, offload reliable operations
  to tools, and measure prompt changes with evals.
- **Corey Haines** — marketingskills: activate by task intent, load product marketing context
  first, ask only for missing task context, keep adjacent skills separate, and return structured
  marketing outputs.
- **Daniele Procida** — Diátaxis: keep different information purposes separate; applied here
  to distinguish skill instructions, context, references, and policies.
- **Simon Willison** — prompt-injection threat model: fetched/retrieved text is data unless
  explicitly admitted as operational instruction.
- **Hamel Husain** — eval-first iteration and failure-driven testing.
- **Erika Hall** — research question before mechanism; applied to keep the user's actual job
  separate from whichever skill/router mechanism handles it.
