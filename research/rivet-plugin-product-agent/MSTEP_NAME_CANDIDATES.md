## Final name

# **Alt-ssembly Required**

Planned AoA id: `alt-ssembly-required`

Tagline:

**Because “the code runs” is not the same thing as “the product is built.”**

Why it won:
- keeps the recognizable phrase `Assembly Required`;
- `Alt-` gives it the keyboard/computer joke and an alternate-path meaning;
- broad enough for greenfield product building and repair;
- naturally describes the agent's actual job: assemble code, UX, runtime, adapters, data/export, settings, diagnostics, packaging, tests, evidence, and release into one coherent product;
- matches the M-Step / Michael S. naming pattern: joke first, real intellectual/technical method underneath.

Canonical short invocation candidates:

```text
activate Alt-ssembly Required
Alt-ssembly this
run Alt-ssembly
assembly check
```

## Naming rule retained

Avoid generic job-title names like `Plugin Developer Agent` or `Product Engineer`.

Prefer:

`ordinary technical object or coding phrase + funny/intellectual twist + useful second meaning`

The joke should survive contact with the documentation. If the name needs a paragraph to explain it, it is not sharp enough.
